# Start with one successful conversion

[繁體中文](#繁體中文) · [Product and requirements](../README.md) · [Report a reproducible issue](https://github.com/harryjia1007/NotchGlass-showcase/issues/new?template=bug-report.yml)

This guide describes the public 1.5.15 workflow. A guide is not a claim that every
Mac, file or player has been tested. Updates to this page do not update your app.

## Install and activate

1. Open your Gumroad receipt or purchase content. Download the DMG linked to that purchase, not a source-code archive from this repository.
2. Drag NotchGlass to Applications, then open it from Applications. The release is Developer ID signed and Apple-notarized. A normal first-open confirmation can still appear.
3. Find the **License Key** in your purchase content and enter it in NotchGlass Settings. The purchase permits up to two Macs. Do not post the key in an issue or screenshot.
4. If the download or key is missing, contact [support](mailto:harryjia1007@gmail.com) privately from the order email. Do not make a second purchase just to recover access.

If macOS says the app is damaged or cannot be verified, stop and contact support.
Do not disable Gatekeeper, run an unknown command, or reset your Keychain.

## Try a PNG to JPEG conversion

Use a non-sensitive PNG image that you own. Keep the original.

1. Drag the file toward the notch and drop it on **Convert**.
2. Select JPEG from the available output formats, then start the conversion.
3. Open the resulting file in Preview. Check the image and dimensions before using it.
4. Repeat with another image if this is a workflow you use often. A successful conversion of one file does not guarantee every format or document will work.

JPEG does not preserve transparency. For images that need a transparent background,
keep a suitable format such as PNG. For complex PDF-to-Word conversions, inspect
tables, fonts and layout; scanned-document OCR is not included.

## Music and files are separate workflows

You do not need to set up a music player to try image conversion. Music controls
depend on the source, app version and macOS Automation permissions. Browser
fallback has fewer capabilities. If a control fails or permissions never appear,
report the source and versions; do not disable system protections.

Saving into iCloud Drive is not confirmation that macOS has finished uploading.
AirDrop also depends on the receiving device and system settings.

## Update without losing your settings

Download the newer release from the same Gumroad purchase. Quit NotchGlass,
replace the app in Applications, and reopen it. Do not delete preferences or
Keychain entries. Confirm the running version before reporting a problem.

### 先完成一個 PNG → JPEG

使用你擁有且不含私人資料的 PNG，保留原檔。拖到瀏海的 **Convert**，選擇 JPEG，再開始轉換。
完成後用「預覽程式」打開結果，確認圖片與尺寸。JPEG 不保留透明背景，需要透明背景時不要改成 JPEG。
這項圖片測試不需要先設定音樂播放器；不要為了試轉檔先處理所有音樂權限。

PDF 轉 Word 的表格、字型和版面仍需檢查，不含掃描 OCR。存入 iCloud Drive 也不代表 macOS 已上傳完成。
